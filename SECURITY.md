# Security Policy

## Supported version

Security reports are accepted for the latest public release of Job Learning
Planner. Older versions do not have a guaranteed backport policy.

## Reporting a vulnerability

Do not disclose vulnerability details in a public issue, discussion, or pull
request.

For the public repository, report vulnerabilities through GitHub Private
Vulnerability Reporting once that channel is available. Use the repository's
**Security** tab and choose **Report a vulnerability**. If the private channel
is not yet available, do not publish technical details in a public issue; wait
until the repository owner enables the private reporting channel.

Useful reports identify the affected version, impact, reproduction conditions,
and any safe mitigation. Do not include real user state, job descriptions,
credentials, or other private data in a report.
